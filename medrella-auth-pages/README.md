# Medrella Authentication UI

This is a standalone Next.js project containing only the Medrella Login and Sign Up pages.

## Pages
- `/login` — Login UI
- `/signup` — Create account UI

## Run locally
1. Extract this folder.
2. Open a terminal in `medrella-auth-pages`.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000/login` or `http://localhost:3000/signup`.

The hospital hero image is stored at `public/images/hospital-auth-hero.jpg`. Authentication actions are UI-only and need a backend/provider integration for real sign-in and registration.
